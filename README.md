# 🎉 EventEase

A modern RSVP Event Management System built with React, Node.js, Express, and MongoDB.

## 🚀 Overview

EventEase is a full-stack event management application that allows users to explore events and manage event RSVPs through an interactive and user-friendly interface.

## ✨ Features

- 📅 Event Management
- 🎟️ RSVP functionality
- 👥 User-friendly event interface
- 🔐 Backend API integration
- 💾 MongoDB database integration
- 📱 Responsive design
- ⚡ Interactive React frontend

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
